Additional primary specification pages, read online:

- [Estonian Defence Forces, HK MP-5A2](https://mil.ee/en/hk-mp-5a2-submachine-gun/):
  680 mm, 225 mm barrel, 2.54 kg with empty magazine, 9×19, 15/30 capacity.
- [Manufacturer class page](https://www.heckler-und-koch.com/en/Products/Military%20and%20Law%20Enforcement/Submachine%20guns/MP5):
  closed bolt, roller-delayed class, right ejection, select fire. Exact weights
  vary with configuration. Relay 9's 2.54 kg is an intended class target, never
  claimed as a measurement of a hollow game mesh.
- [C.I.P. 9 mm exterior reference](https://bobp.cip-bobp.org/uploads/tdcc/tab-iv/tabivcal-en-page28.pdf):
  the family's accepted visual cartridge/case builder is reused read-only.

Finish comparisons use the daylight exhibition photographs `navy2.jpg` and
`trigger-ref.jpg` (same displayed issued guns, different angles), together with
`daylight.jpg`. The edited studio images remain auxiliary side/form comparisons.
All are neutral-balanced before color sampling. No reference pixels enter maps.

Finish round 2 also measures the upper issued receiver in `navy2.jpg`: a native
700×22-pixel ribbon directly below the crest, excluding its narrow rim glint.
An approximate 230-mm receiver envelope supplies scale. `src/wear_metrics.py`
records the region, thresholds, half-mm binning, chip/gap lengths and observed
gray/bright area split. The independent seeded procedural pattern uses those
statistics as a target; neither the reference pixels nor its chip outlines
enter the asset. Mixed light and the envelope scale limit the measurement.
