Published primary sources read online:

- [California DOJ, manufacturer-declared aluminum trigger guard](https://oag.ca.gov/firearms/safety-device/870-express-aluminum-two-dot-iss-trigger-guard):
  primary state record confirming an aluminum housing/guard in this class.
  Our original cast aluminum plate/bow uses a dark anodized finish, visually
  checked against the dark guards in the used reference photos; the precise
  coating chemistry of those photographed specimens is not established.

- [Remington 870 owner manual](https://www.remarms.com/sites/default/files/documents/870%20Manual%20Final.pdf),
  manufacturer: visual arrangement of crossbolt, action release, twin action
  bars, carrier and exploded parts diagram. The server timed out on local PDF
  retrieval; the indexed manual is readable online. It supplies no motion
  tolerances for this model. Internal geometry/timing are visual estimates.
- [Mossberg 500 manufacturer class comparison](https://www.mossberg.com/500-hunting-all-purpose-field-50120.html):
  12 gauge / 3 in chamber, wood, pump action, 13.87 in pull and 7.5 lb. It has a
  longer field barrel and different controls; these are not copied.

The shell is a visual 12-gauge 2¾ in class shell: about 22.4 mm rim, 20.1 mm hull,
57.5 mm closed length, 69.8 mm opened hull. The nominal shell length describes
the opened hull, not the loaded envelope. These external silhouette estimates
are not cartridge or chamber manufacturing specifications. Mass is a design
class target, not a measured or simulated mass of the game mesh.

## Visible-feed correction — 2026-10-29

The US Navy's *Gunner's Mate*, NAVEDTRA 14110, printed pp.3-27–3-29,
[M870 operating cycle, online reproduction](https://www.tpub.com/gunners/68.htm),
is the primary sequence source (US federal training text, public domain;
Integrated Publishing hosts the reproduction). Read online, not downloaded
as code or used as a modeling input. Its named stages establish:

| Visible stage | Primary description used |
| --- | --- |
| Tube release and following-shell retention | Feeding: the left latch releases the first shell at the end of rear travel; the right latch intercepts the second shell |
| Carrier lift | Loading: forward slide travel raises the depressed carrier into the returning bolt's path |
| Bolt feeding | Loading: the advancing bolt picks up the shell and the carrier moves clear |
| Extraction | Extracting: the claw over the bolt face holds the shell rim during withdrawal |
| Ejection | Ejecting: the shell base meets the left ejector spring shoulder, turning its front out through the port |
| Latch reset | Loading: the returning right action bar releases the following shell to the left latch |

The exterior cartridge dimensions remain the original visual envelope above.
The sequence source publishes no millimeter dimensions for our fictional
carrier, chamber relief, latch noses or ejector position. Those are original
visual estimates, corrected against the actual shell surfaces and clearance
sweeps. No hidden working cam, spring design or firing mechanism is supplied.
